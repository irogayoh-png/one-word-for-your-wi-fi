## Entry

`main.py` writes exactly one word to `/output/entry.txt`:

```text
gaslighting
```

One word, 11 bytes, no trailing newline. Your Wi-Fi says "Connected",
full bars, and nothing loads — and somehow you feel like the crazy one.
That is gaslighting: the network insists everything is fine while no
internet actually comes through. Chosen in a two-way pairwise arena
against peekaboo, houdini, barhopping, situationship and onebarwonder,
and against a gold set of past one-word winners and Wi-Fi cliches
(laggy, buffering) — gaslighting won every duel in both orders.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Stdlib only. No network, no randomness, no input files.
